# Отчёт по лабораторной работе: доработка проекта WebAssembly `budget_planner_project`

## 1. Цель работы

Цель работы — изучить готовый проект на WebAssembly, разобраться в его структуре и принципе работы, установить компилятор Emscripten, добиться компиляции и запуска приложения, а также самостоятельно реализовать улучшение проекта и подготовить результат для публикации в GitHub.

## 2. Изучение проекта

В архиве проекта находится приложение **Budget Planner / Expense Tracker**, предназначенное для учёта расходов. Пользователь может добавлять расходы, указывать дату, категорию, сумму и описание, после чего данные отображаются в таблице. Также приложение считает общую сумму расходов и суммы по категориям.

Структура проекта:

```text
budget_planner/
├── README.md
├── index.html
├── app.js
├── index.js
├── index.wasm
├── main.c
├── makefile
└── makefile-old-copy
```

Основные файлы проекта:

- `main.c` — основная логика приложения на языке C. Здесь описаны структуры данных, массив расходов, функции добавления, удаления и очистки записей, а также расчёт общей суммы и сумм по категориям.
- `index.html` — HTML-страница с интерфейсом приложения: форма добавления расхода, таблица расходов и блок итогов.
- `app.js` — JavaScript-код, который связывает HTML-интерфейс с WebAssembly-модулем. Через JavaScript вызываются функции, экспортированные из C-кода.
- `index.js` — JavaScript-файл, сгенерированный Emscripten. Он загружает и инициализирует WebAssembly-модуль.
- `index.wasm` — бинарный WebAssembly-файл, полученный после компиляции `main.c`.
- `makefile` — файл для автоматической сборки проекта командой `make`.

## 3. Принцип работы приложения

Проект построен по схеме взаимодействия C, WebAssembly и JavaScript.

Логика хранения и обработки данных реализована на языке C. В файле `main.c` определена структура `ExpenseEntry`, которая хранит дату, категорию, сумму и описание расхода. Все расходы сохраняются в массиве `expenses`, максимальное количество записей ограничено значением `MAX_EXPENSES`.

После компиляции C-код превращается в WebAssembly-модуль. JavaScript-код вызывает экспортированные функции WebAssembly, например:

- `_jsAddExpense` — добавление нового расхода;
- `_jsDeleteExpense` — удаление расхода;
- `_jsClearAllExpenses` — очистка списка расходов;
- `_jsGetTotalExpenses` — получение общей суммы расходов;
- `_getExpenseJSON` — получение данных о расходе в формате JSON;
- `_getCategoryTotalJSON` — получение итоговой суммы по категории в формате JSON.

Файл `app.js` отвечает за обработку событий в браузере: отправку формы, нажатие кнопок, обновление таблицы и блока итогов. Таким образом, C-код выполняет вычисления, а JavaScript отвечает за отображение результата пользователю.

## 4. Установка Emscripten

Для компиляции проекта был установлен Emscripten SDK. Установка выполняется по инструкции с официального сайта Emscripten.

Команды для установки:

```bash
git clone https://github.com/emscripten-core/emsdk.git
cd emsdk
emsdk install latest
emsdk activate latest
emsdk_env.bat
```

Для Linux/macOS последняя команда будет другой:

```bash
source ./emsdk_env.sh
```

После активации окружения была проверена доступность компилятора:

```bash
emcc --version
```

Если команда выводит версию Emscripten, значит компилятор установлен и готов к работе.

**Место для скриншота:** `screenshot_01_emscripten_version.png`

## 5. Компиляция проекта

После установки Emscripten был открыт каталог проекта:

```bash
cd budget_planner
```

Так как в проекте уже есть `makefile`, сборка выполняется командами:

```bash
make clean
make
```

В результате создаются обновлённые файлы:

```text
index.js
index.wasm
```

Если на Windows не установлен `make`, можно выполнить команду компиляции вручную:

```bash
emcc main.c -s WASM=1 -s ASSERTIONS=1 -s MODULARIZE=1 -s EXPORT_NAME="'BudgetPlanner'" ^
-s EXPORTED_FUNCTIONS="[\"_main\",\"_showHelloMessage\",\"_jsAddExpense\",\"_jsDeleteExpense\",\"_jsClearAllExpenses\",\"_jsGetTotalExpenses\",\"_jsGetExpenseCount\",\"_jsGetCategoryCount\",\"_getExpenseJSON\",\"_getCategoryTotalJSON\",\"_freeMemory\",\"_malloc\",\"_free\"]" ^
-s EXPORTED_RUNTIME_METHODS="[\"ccall\", \"cwrap\", \"stringToUTF8\", \"UTF8ToString\"]" ^
-O3 --llvm-opts 2 --llvm-lto 1 -s ALLOW_MEMORY_GROWTH=1 -o index.js
```

**Место для скриншота:** `screenshot_02_project_build.png`

## 6. Запуск приложения

WebAssembly-приложение нельзя корректно запускать простым открытием `index.html` через проводник, так как браузер может заблокировать загрузку `.wasm`-файла. Поэтому проект запускается через локальный HTTP-сервер.

Команда запуска сервера:

```bash
python -m http.server 8000
```

После этого приложение открывается в браузере по адресу:

```text
http://localhost:8000/
```

**Место для скриншота:** `screenshot_03_local_server.png`

После запуска была проверена работа приложения: добавление расходов, отображение строк в таблице, подсчёт общей суммы, подсчёт сумм по категориям, удаление записи и очистка списка расходов.

**Место для скриншота:** `screenshot_04_app_before_improvement.png`

## 7. Реализованное улучшение проекта

В качестве самостоятельного улучшения был добавлен блок **Filter and Export**.

Реализованы следующие возможности:

1. Фильтрация расходов по категории.
2. Отображение суммы только по видимым строкам таблицы.
3. Экспорт видимых строк в CSV-файл.

Фильтр работает без изменения данных внутри WebAssembly-модуля. Все расходы по-прежнему хранятся и обрабатываются в C-коде, а JavaScript получает данные через уже существующую функцию `_getExpenseJSON`. Это сохраняет исходную архитектуру проекта: WebAssembly отвечает за данные и вычисления, JavaScript — за интерфейс.

Изменения были внесены в файлы:

- `index.html` — добавлен новый блок интерфейса с выпадающим списком категорий, кнопкой сброса фильтра, кнопкой экспорта CSV и полем `Visible total`.
- `app.js` — добавлены функции чтения всех расходов из WebAssembly, фильтрации строк, пересчёта видимой суммы и экспорта текущей таблицы в CSV.
- `README.md` — добавлено описание улучшения и актуальные команды сборки.

Для публикации проекта в один репозиторий можно использовать следующие команды:

