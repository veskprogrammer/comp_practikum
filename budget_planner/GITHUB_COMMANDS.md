# GitHub publish commands

Run these commands inside the `budget_planner` folder.

```bash
git init
git add .
git commit -m "Complete WebAssembly budget planner project"
git branch -M main
git remote add origin https://github.com/USERNAME/budget-planner-webassembly.git
git push -u origin main
```

Replace `USERNAME` with your GitHub username.

If the repository already exists locally and has a remote, use:

```bash
git add .
git commit -m "Complete WebAssembly budget planner project"
git push
```
