# Лабораторная работа 10. Генерация изображений веб-сервером по запросу

## Цель работы

Целью лабораторной работы является разработка веб-приложения, которое по запросу пользователя генерирует изображение на сервере и возвращает его в формате JPG. В ходе работы необходимо реализовать маршруты для получения логина автора, отображения HTML-формы, обработки данных формы, генерации изображения и проверки корректности введённых параметров.

## Задание

Необходимо реализовать веб-приложение со следующими маршрутами:

- `/login` — маршрут с методом GET, возвращающий JSON-ответ с логином автора в Moodle;
- `/makeimage` — маршрут, поддерживающий методы GET и POST;
- при GET-запросе `/makeimage` должна отображаться HTML-форма с полями `width`, `height`, `text`;
- при POST-запросе `/makeimage` сервер должен принять данные формы, сгенерировать изображение заданного размера и вернуть его как JPG-файл;
- при некорректных значениях ширины или высоты должна отображаться та же форма с сообщением `message: "Invalid image size"`.

Дополнительно в проекте реализован асинхронный предпросмотр изображения размером 100×100 без перезагрузки страницы.

## Используемые технологии

Для выполнения лабораторной работы были использованы следующие технологии:

- язык программирования Python;
- микрофреймворк Flask для реализации веб-сервера и маршрутов;
- библиотека Pillow для создания и обработки изображений;
- HTML и CSS для создания страницы с формой;
- JavaScript для реализации дополнительного асинхронного предпросмотра изображения.

Для запуска проекта необходимо установить Python 3 и создать виртуальное окружение.

```powershell
.\venv\Scripts\Activate.ps1
```

Активация виртуального окружения в Windows CMD:


В качестве значения поля `author` используется логин Moodle:

```text
1154202
```

## Реализация маршрута `/makeimage`

Маршрут `/makeimage` поддерживает два метода: GET и POST.

При GET-запросе сервер возвращает HTML-страницу с формой. В форме расположены поля для ввода ширины изображения, высоты изображения и текста, который будет расположен на изображении.

Форма отправляет данные методом POST в формате `application/x-www-form-urlencoded`:

```html
<form method="POST" action="/makeimage" enctype="application/x-www-form-urlencoded">
    <input id="width" name="width" type="number" min="10" max="2000" required>
    <input id="height" name="height" type="number" min="10" max="2000" required>
    <input id="text" name="text" type="text" required>
    <button type="submit">Создать JPG</button>
</form>
```

При POST-запросе сервер получает данные из формы, проверяет корректность размеров и создаёт изображение. Если данные корректные, пользователю возвращается готовое JPG-изображение. Если данные некорректные, возвращается форма с сообщением об ошибке.

## Валидация данных

Для проверки параметров изображения была реализована функция `validate_size`. Она проверяет, что `width` и `height` являются целыми числами и находятся в допустимом диапазоне от 10 до 2000 пикселей.

```python
def validate_size(width_raw: str, height_raw: str) -> tuple[int | None, int | None, bool]:
    try:
        width = int(width_raw)
        height = int(height_raw)
    except (TypeError, ValueError):
        return None, None, False

    valid = MIN_SIZE <= width <= MAX_SIZE and MIN_SIZE <= height <= MAX_SIZE
    return width, height, valid
```

Если пользователь вводит некорректный размер, сервер возвращает страницу с формой и выводит сообщение красным цветом:

```text
message: "Invalid image size"
```

## Генерация изображения

Для генерации изображения используется библиотека Pillow. Сервер создаёт новое RGB-изображение заданного размера, заливает его светло-серым цветом и рисует переданный пользователем текст по центру.

```python
def generate_image(width: int, height: int, text: str) -> bytes:

    draw = ImageDraw.Draw(image)
    font = ImageFont.load_default()

    safe_text = text.strip() or "No text"

    output = BytesIO()
    image.save(output, format="JPEG", quality=92)
    return output.getvalue()
```

После создания изображение сохраняется в оперативной памяти в формате JPEG. Отдельный файл на диск не создаётся, так как результат сразу возвращается в HTTP-ответе.

## Возврат JPG-файла

При успешной генерации сервер возвращает бинарные данные изображения с MIME-типом `image/jpeg`:

```python
jpg_data = generate_image(width, height, text)
return Response(jpg_data, mimetype="image/jpeg")
```

Браузер автоматически отображает полученное изображение как обычный JPG-файл. Base64 и отдельная HTML-страница для результата не используются.

## Дополнительное усложнение

В работе также реализован дополнительный маршрут `/thumbnail`, который используется для асинхронного предпросмотра изображения размером 100×100. Предпросмотр обновляется без перезагрузки страницы после изменения данных в форме.

```python
@app.post("/thumbnail")
def thumbnail() -> Response:
    width_raw = request.form.get("width")
    height_raw = request.form.get("height")
    text = request.form.get("text", "")
    _, _, valid = validate_size(width_raw, height_raw)

    if not valid:
        return Response(status=400)

    jpg_data = generate_image(100, 100, text)
    return Response(jpg_data, mimetype="image/jpeg")
```

Также добавлен маршрут `/health`, который возвращает JSON-ответ и может использоваться для быстрой проверки работоспособности сервера:

```json
{"status":"ok"}
```

## Ход выполнения работы

В ходе выполнения лабораторной работы был создан проект на Flask. Сначала были подключены необходимые зависимости: Flask для реализации веб-сервера и Pillow для генерации изображения. Затем был реализован маршрут `/login`, возвращающий JSON-ответ с логином автора.

После этого был реализован маршрут `/makeimage`. При GET-запросе он отображает HTML-форму с полями `width`, `height` и `text`. При POST-запросе данные формы считываются на сервере, проходят проверку и используются для создания JPG-изображения.

Для проверки корректности данных была добавлена валидация ширины и высоты. Если одно из значений не является положительным целым числом или выходит за допустимый диапазон, сервер не создаёт изображение, а возвращает форму с сообщением `message: "Invalid image size"`.

Генерация изображения выполняется полностью на сервере. Создаётся изображение нужного размера, задаётся фоновый цвет, после чего на изображении рисуется текст пользователя. Затем изображение сохраняется в память в формате JPEG и отправляется клиенту с заголовком `Content-Type: image/jpeg`.

Для повышения оценки был добавлен асинхронный предпросмотр изображения. При изменении данных формы JavaScript отправляет запрос на маршрут `/thumbnail`, получает изображение 100×100 и отображает его на той же странице без перезагрузки.
