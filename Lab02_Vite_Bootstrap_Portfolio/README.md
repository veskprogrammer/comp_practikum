# Лабораторная работа №2

## Тема

Сборка сайта с помощью Node.js, npm, Vite, SASS и Bootstrap.

## Описание

В рамках лабораторной работы был создан учебный сайт-портфолио.  
Проект демонстрирует использование Vite для сборки frontend-проекта, Bootstrap для адаптивной сетки и компонентов, а также SCSS для кастомизации дизайна.

## Используемые технологии

- HTML
- SCSS
- JavaScript
- Bootstrap
- Vite
- Node.js
- npm

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

Собрать проект:

```bash
npm run build
```

Создан адаптивный сайт-портфолио с кастомным дизайном на основе Bootstrap и SCSS.
