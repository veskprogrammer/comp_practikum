# Отчёт по лабораторной работе №2

## Тема

Сборка сайта с помощью Node.js, npm, yarn, SASS, Vite.

## Цель работы

Изучить процесс создания и сборки frontend-проекта с использованием Node.js, npm, Vite, SASS и CSS-фреймворка Bootstrap. Создать пример сайта-портфолио с собственным кастомным дизайном.

## Используемые технологии

В ходе выполнения лабораторной работы использовались следующие технологии:

- Node.js — среда выполнения JavaScript;
- npm — менеджер пакетов;
- Vite — инструмент для быстрой сборки frontend-проектов;
- Bootstrap — CSS-фреймворк для создания адаптивных интерфейсов;
- SASS/SCSS — препроцессор CSS;
- HTML, CSS, JavaScript.

## Ход работы

Сначала был создан проект на основе Vite. Для этого использовалась команда создания нового проекта. После создания проекта были установлены зависимости Bootstrap и SASS.

Место для скриншота 1 — создание проекта и установка зависимостей.

Далее была подготовлена структура проекта. Основные файлы проекта: `index.html`, `src/main.js`, `src/scss/styles.scss`.

Место для скриншота 2 — структура проекта в редакторе кода.

В файле `main.js` были подключены стили SCSS и JavaScript-компоненты Bootstrap.

Место для скриншота 3 — файл `main.js`.

В файле `styles.scss` были изменены переменные Bootstrap и добавлены собственные стили. Были настроены цвета, фон главного блока, карточки проектов, кнопки, секция навыков и подвал сайта.

Место для скриншота 4 — файл `styles.scss`.

В файле `index.html` была создана структура сайта-портфолио: навигационное меню, главный экран, блок «Обо мне», блок проектов, контакты и подвал.

Место для скриншота 5 — файл `index.html`.

После этого проект был запущен с помощью команды:

```bash
npm run dev
```

Место для скриншота 6 — запуск проекта в терминале.

В браузере был открыт локальный адрес Vite, после чего был проверен внешний вид сайта и адаптивность интерфейса.

Место для скриншота 7 — готовый сайт в браузере.

## Результат работы

В результате выполнения лабораторной работы был создан сайт-портфолио с использованием Vite, Bootstrap и SCSS. Сайт содержит адаптивную навигацию, главный экран, блок информации о разработчике, карточки проектов и контактную информацию. Внешний вид сайта был изменён с помощью кастомных SCSS-стилей.

## Вывод

В ходе лабораторной работы были изучены основы сборки frontend-проекта с помощью Vite и npm. Также были закреплены навыки подключения Bootstrap, использования SCSS и создания собственного дизайна сайта. Полученный проект можно загрузить на GitHub и использовать как пример учебного сайта-портфолио.
